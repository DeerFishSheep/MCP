# MCP

自用 MCP 服务器合集。一个 MCP 一个文件夹，各自独立，互不依赖。

## 目录

| 目录 | 说明 |
|---|---|
| [`free-search/`](free-search/) | 免费联网搜索：多引擎回退链 + 网页正文抓取 + 平台/视频/天气搜索，Streamable HTTP + Bearer 鉴权，可远程供任何 MCP 客户端调用 |

## 约定

- 每个 MCP 放自己的子目录，目录名即 MCP 名（小写连字符）。
- 每个子目录自带 `README.md`（装法、启动方式、工具列表）和 `docs/PROGRESS.md`（进度）。
- 仓库根只放这份索引和全局 `.gitignore`，不放任何单个 MCP 的代码。
- 新增 MCP：建目录 → 写代码 → 在这张表里加一行 → 提交。
